# Manual de usuario - SIS4S

Este manual explica como usar el Sistema Integral de Servicios 4 Soles para administrar residentes, pagos de agua, reportes, cortes, reconexiones y recibos.

## 1. Acceso al sistema

1. Entra a la pagina del sistema.
2. Inicia sesion con tu correo y contrasena.
3. Segun tu rol, el sistema te enviara a tu panel:
   - Residente: panel de pago e historial.
   - Tesorera: reportes y registro de pagos del circuito.
   - Representante: residentes, personal y seguimiento operativo.
   - Cuadrilla de cortes: cortes y reconexiones pendientes.
   - Administrador: configuracion general del sistema.

Si olvidaste tu contrasena, usa la opcion de recuperacion en la pantalla de inicio de sesion.

## 2. Registro de residente

1. Selecciona "Registrate" en la pantalla de inicio.
2. Captura tus datos de cuenta.
3. Completa tu perfil:
   - Telefono.
   - Sexo.
   - Tipo de tenencia.
   - Circuito.
   - Edificio y departamento.
   - Datos del propietario si eres inquilino.
4. Guarda el registro.

El departamento debe escribirse como numero con letra opcional, por ejemplo `314` o `314A`.

## 3. Panel de residente

En el panel puedes consultar:

- Estado del servicio de agua.
- Mes actual.
- Monto base.
- Total con comisiones al pagar con tarjeta.
- Historial de pagos.
- Recibos y folios.

### Pago con tarjeta

1. En la tarjeta de pago, elige cuantos meses quieres pagar.
2. Usa el selector de meses para pagar el mes actual o adelantar hasta 12 meses.
3. Revisa el total.
4. Presiona "Pagar con Mercado Pago".
5. Completa el pago en Mercado Pago.
6. Al volver al sistema, veras si el pago fue aprobado, pendiente o fallido.

Si tu servicio esta cortado, el pago incluye el mes actual y el cargo de reconexion. La reconexion fisica queda pendiente hasta que la cuadrilla la confirme.

### Recibos

1. Abre el menu de usuario.
2. Entra a "Recibos".
3. Consulta tus folios.
4. Descarga el PDF del recibo cuando lo necesites.

## 4. Panel de tesorera

La tesorera administra pagos y reportes del circuito asignado.

### Registrar pago en efectivo o transferencia

1. Entra a la seccion de pagos del circuito.
2. Busca al residente por nombre, correo, edificio o departamento.
3. Presiona "Efectivo" o "Transferencia".
4. En el modal, selecciona los meses pagados:
   - Atrasados.
   - Mes actual.
   - Adelantados.
5. Confirma el registro.

El sistema registra un folio por cada mes pagado. Si algun mes ya estaba pagado, se omite para evitar duplicados.

### Reporte de residentes

1. Entra a reportes.
2. Elige filtros como edificio, estado o rango de meses.
3. Descarga el archivo Excel.

### Reporte financiero

1. Entra a reporte financiero.
2. Selecciona mes individual o rango.
3. Revisa pagos, ingresos adicionales, gastos y saldo.
4. Descarga el Excel si necesitas compartirlo.

### Gastos e ingresos adicionales

En reporte financiero puedes agregar, editar o eliminar:

- Gastos del circuito.
- Ingresos adicionales.

Usa conceptos claros y montos correctos para mantener los reportes confiables.

## 5. Panel de representante

El representante puede consultar residentes de su circuito y coordinar personal.

Funciones principales:

- Ver residentes y morosos.
- Consultar pagos del circuito.
- Crear personal del circuito, como tesorera o cuadrilla.
- Cambiar roles permitidos dentro del circuito.
- Revisar reportes disponibles.

El representante solo puede operar sobre su circuito asignado.

## 6. Panel de cuadrilla de cortes

La cuadrilla atiende ordenes operativas.

### Confirmar corte

1. Abre la lista de pendientes de corte.
2. Revisa residente, edificio y departamento.
3. Confirma el corte cuando se haya realizado.

### Confirmar reconexion

1. Abre la lista de pendientes de reconexion.
2. Revisa el residente.
3. Confirma la reconexion cuando el servicio haya sido restablecido.

## 7. Panel de administrador

El administrador configura y supervisa todo el sistema.

Funciones principales:

- Crear y editar circuitos.
- Activar o desactivar circuitos.
- Configurar montos mensuales y reconexion.
- Asignar representantes.
- Crear, editar o eliminar representantes y tesoreras.
- Cambiar roles de usuarios.
- Registrar pagos por efectivo o transferencia para meses atrasados, actuales o adelantados.

### Registrar pagos manuales como admin

1. Entra a la lista de residentes.
2. Presiona "Efectivo" o "Transferencia" en el residente.
3. Selecciona los meses pagados.
4. Confirma el registro.

## 8. Estados del servicio

- Activo: servicio normal.
- Pendiente de corte: tiene atraso y puede ser enviado a corte.
- Cortado: el servicio ya fue suspendido.
- Pendiente de reconexion: el pago de reconexion fue registrado y falta la visita de cuadrilla.

## 9. Buenas practicas

- No compartas tu contrasena.
- Verifica residente, edificio y departamento antes de registrar pagos manuales.
- Revisa el metodo de pago antes de confirmar.
- Descarga reportes solo cuando sean necesarios.
- Cierra sesion en equipos compartidos.
- Reporta datos incorrectos al administrador o representante.

## 10. Soporte operativo

Si algo no coincide:

1. Revisa el folio del pago.
2. Verifica el mes y anio registrados.
3. Confirma el metodo de pago.
4. Contacta a la tesorera, representante o administrador segun corresponda.
